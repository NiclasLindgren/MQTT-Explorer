## 6. How to Build an EXE

**User:** How do I build an exe file?

**Answer:** Run `yarn --ignore-engines prepare-release` then `yarn --ignore-engines package win`. This copies the built app into `build/clean/` and runs electron-builder to produce a portable .exe and NSIS installer. Output goes to `build/clean/dist/`.

---

## 7. How to Run Dev Mode

**User:** In what way should you run it to dev?

**Answer:** `yarn --ignore-engines dev` — runs webpack dev-server with HMR on port 8080 and launches Electron in parallel.

## 9. Port 8080 Already in Use

**User:** EADDRINUSE error on port 8080.

## 11. Login Credentials

**User:** What are the login credentials?

**Answer:** Credentials are auto-generated on first run and printed to terminal. Three options:
1. Check terminal output for generated username/password
2. Set via env vars: `MQTT_EXPLORER_USERNAME` and `MQTT_EXPLORER_PASSWORD`
3. Skip auth: `MQTT_EXPLORER_SKIP_AUTH=true`
